### Sintaxis
```
router#configure terminal
```
Abreviatura: `Conf t`
### Descripción de propósito/uso

Permite acceder al modo de configuración global del router o switch para poder realizar configuraciones básicas o especificas.
### Ejemplo
```
router#configure terminal
router(config)#
```
