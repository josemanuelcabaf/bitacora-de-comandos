#router  #switch  #IPv4 #IPv6
### Sintaxis
```
router(config)#hostname [string] 
```
Abreviatura: `host`
### Descripción de propósito/uso
### Parámetros
- `[string]` .- Aquí se debe poner el nombre que quieres que el dispositivo muestre. Sólo se permite
    - Letras
    - Dígitos
    - Guiones `-`
    - Máximo 63 caracteres
### Ejemplo
```
router(config)#hostname RF1
```
