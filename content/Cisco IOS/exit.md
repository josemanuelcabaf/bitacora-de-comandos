#router #switch #IPv4 #IPv6 
### Sintaxis
```
router(config)#exit
```
```
router(config-modo)#exit
```
Abreviatura: No hay
### Descripción de propósito/uso

Se usa para retroceder en los modos de sistema operativo de Cisco IOS, específicamente para regresar al modo de configuración global (desde una configuración especifica) o al modo privilegiado (desde la configuración global).
### Ejemplo
```
router(config-modo)#exit
router(config)#exit
router#

```
