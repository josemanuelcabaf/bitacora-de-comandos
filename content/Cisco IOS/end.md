#router #switch #IPv4 #IPv6 
### Sintaxis
```
router(config-modo)#end 
```
Abreviatura: No hay
### Descripción de propósito/uso
Este comando se usa para poder regresar del modo de configuración específica al modo privilegiado sin tener que pasar por el modo de configuración global con el comando exit. Su equivalente es `Ctrl+Z`
### Ejemplo
```
router(config-modo)#end 
router#
```
